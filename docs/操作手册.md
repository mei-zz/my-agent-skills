## 1. Skill 结构规范

### 1.1 目录结构

```
my-agent-skills/
├── README.md                    # 项目说明文档
── docs/                        # 文档目录
│   └── 操作手册.md
└── skills/                      # Skills 根目录
    ├── api-docs-writer/         # Skill 名称（小写+连字符）
    │   ├── SKILL.md             # Skill 定义文件（必需）
    │   └── scripts/             # 脚本目录（可选）
    │       └── test.js          # 测试脚本
    ├── code-review-pro/
    │   ├── SKILL.md
    │   └── scripts/
    │       └── test.js
    ├── backend-team/            # 部门目录（可选）
    │   └── api-helper/
    │       ├── SKILL.md
    │       ── scripts/
    │           └── test.js
    └── frontend-team/
        ── component-builder/
            ├── SKILL.md
            └── scripts/
                └── test.js
```

### 1.2 SKILL.md 文件格式

每个 Skill 必须包含 `SKILL.md` 文件，格式如下：

```markdown
---
name: skill-name                 # Skill 名称（小写+连字符，唯一标识）
description: Skill 的简短描述     # 用于搜索和展示
version: 1.0.0                   # 版本号（语义化版本）
author: github-username          # 作者 GitHub 用户名
agents: [opencode, claude-code, cursor]  # 支持的 AI 代理
---

# Skill 标题

## 工作流

1. 步骤一
2. 步骤二
3. 步骤三

## 使用说明

详细说明如何使用此 Skill。

## 测试

运行测试脚本验证 skill 功能：
```bash
node skills/skill-name/scripts/test.js
```
```

### 1.3 命名规范

- **Skill 名称**：使用小写字母和连字符，如 `api-docs-writer`
- **目录名称**：与 Skill 名称一致
- **部门目录**：使用小写+连字符，如 `backend-team`

## 2. 创建新 Skill

### 2.1 创建 Skill 目录

```bash
# 通用 Skill
mkdir -p skills/my-new-skill/scripts

# 部门 Skill
mkdir -p skills/backend-team/my-new-skill/scripts
```

### 2.2 创建 SKILL.md

在 Skill 目录下创建 `SKILL.md` 文件：

```bash
# 使用模板创建
cat > skills/my-new-skill/SKILL.md << 'EOF'
---
name: my-new-skill
description: 我的新 Skill 描述
version: 1.0.0
author: mei-zz
agents: [opencode, claude-code, cursor]
---

# My New Skill

## 工作流

1. 步骤一
2. 步骤二

## 使用说明

详细说明...
EOF
```

### 2.3 创建测试脚本

在 `scripts/` 目录下创建 `test.js`：

```javascript
const fs = require('fs');
const path = require('path');

function testSkillMdFormat() {
  const skillPath = path.join(__dirname, '..', 'SKILL.md');
  
  if (!fs.existsSync(skillPath)) {
    console.error(' SKILL.md not found');
    return false;
  }
  
  const content = fs.readFileSync(skillPath, 'utf8');
  
  if (!content.startsWith('---')) {
    console.error('❌ Missing YAML frontmatter');
    return false;
  }
  
  const requiredFields = ['name:', 'description:', 'version:', 'author:'];
  for (const field of requiredFields) {
    if (!content.includes(field)) {
      console.error(`❌ Missing required field: ${field}`);
      return false;
    }
  }
  
  console.log('✅ SKILL.md format is valid');
  return true;
}

console.log(' Running Tests...\n');
if (testSkillMdFormat()) {
  console.log('\n✅ All tests passed!');
  process.exit(0);
} else {
  console.log('\n Some tests failed');
  process.exit(1);
}
```

## 3. 本地测试 Skill

### 3.1 运行单个 Skill 测试

```bash
# 测试 api-docs-writer
node skills/api-docs-writer/scripts/test.js

# 测试 code-review-pro
node skills/code-review-pro/scripts/test.js

# 测试部门 skill
node skills/backend-team/api-helper/scripts/test.js
```

### 3.2 运行所有测试

```bash
# 创建测试运行脚本
cat > scripts/run-all-tests.js << 'EOF'
const { execSync } = require('child_process');
const fs = require('fs');
const path = require('path');

function findTestScripts(dir) {
  const tests = [];
  const items = fs.readdirSync(dir, { withFileTypes: true });
  
  for (const item of items) {
    const fullPath = path.join(dir, item.name);
    if (item.isDirectory()) {
      tests.push(...findTestScripts(fullPath));
    } else if (item.name === 'test.js') {
      tests.push(fullPath);
    }
  }
  
  return tests;
}

const skillsDir = path.join(__dirname, '..', 'skills');
const tests = findTestScripts(skillsDir);

console.log(`\n🧪 Found ${tests.length} test(s)\n`);

let passed = 0;
let failed = 0;

for (const test of tests) {
  console.log(`Running: ${path.relative(skillsDir, test)}`);
  try {
    execSync(`node "${test}"`, { stdio: 'inherit' });
    passed++;
  } catch (e) {
    failed++;
  }
  console.log('');
}

console.log('='.repeat(40));
console.log(`Results: ${passed} passed, ${failed} failed`);
process.exit(failed > 0 ? 1 : 0);
EOF

# 运行所有测试
node scripts/run-all-tests.js
```

## 4. 上传到 GitHub

### 4.1 初始化 Git 仓库

```bash
# 进入项目目录
cd my-agent-skills

# 初始化 Git
git init

# 添加所有文件
git add .

# 提交
git commit -m "initial commit: add skills"
```

### 4.2 创建 GitHub 仓库

1. 访问 https://github.com/new
2. 输入仓库名称（如 `my-agent-skills`）
3. 选择 Public（公开）
4. 点击 Create repository

### 4.3 推送到 GitHub

```bash
# 添加远程仓库（替换为你的 GitHub 用户名）
git remote add origin https://github.com/YOUR-USERNAME/my-agent-skills.git

# 重命名分支为 main
git branch -M main

# 推送
git push -u origin main
```

### 4.4 后续更新

```bash
# 修改文件后
git add .
git commit -m "update: add new skill"
git push
```

## 5. 安装和使用 Skill

### 5.1 安装 Skills

```bash
# 安装整个仓库的所有 skills
npx skills install YOUR-USERNAME/my-agent-skills

# 安装时会显示可用的 skills 列表，选择需要安装的
```

### 5.2 搜索 Skills

```bash
# 搜索特定关键词的 skills
npx skills find api

# 注意：搜索功能需要仓库被 skills.sh 平台收录
# 新上传的仓库可能需要等待收录
```

### 5.3 更新 Skills

```bash
# 检查更新
npx skills check

# 更新所有已安装的 skills
npx skills update
```

### 5.4 在 AI 代理中使用

安装后，Skill 会被添加到 `.agents/skills/` 目录。

在 AI 代理（如 Cline、Cursor）中：
1. 打开项目
2. Skill 会自动加载
3. 根据 SKILL.md 中的描述触发相应的功能

## 7. 常见问题

### 7.1 npx skills find 搜索不到我的仓库

**原因**：`npx skills find` 需要仓库被 skills.sh 平台收录。

**解决方案**：
1. 直接使用 `npx skills install YOUR-USERNAME/my-agent-skills` 安装
2. 访问 https://skills.sh/ 提交仓库到平台索引

### 7.2 SKILL.md 格式错误

确保：
- 以 `---` 开头和结束 YAML frontmatter
- 包含必需的字段：`name`、`description`、`version`、`author`
- YAML 格式正确（注意缩进使用空格，不是 Tab）

### 7.3 安装时找不到 Skill

检查：
- `skills/` 目录是否存在
- 每个 Skill 目录下是否有 `SKILL.md`
- `SKILL.md` 中的 `name` 字段是否正确

### 7.4 如何删除已安装的 Skill

```bash
# 删除 .agents/skills/ 目录下的对应 skill
rm -rf .agents/skills/skill-name

# 或者重新运行安装命令，取消选择该 skill
npx skills install YOUR-USERNAME/my-agent-skills
```
