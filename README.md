# my-agent-skills

A collection of agent skills for AI coding assistants.

## Available Skills

### api-docs-writer
根据源代码自动生成符合 OpenAPI 规范的 API 文档。当用户请求写接口文档时触发。

### code-review-pro
专业的代码审查工具，检查代码质量、潜在bug和最佳实践。当用户请求代码审查时触发。

## Installation

Install via skills.sh:

```bash
npx skills install mei-zz/my-agent-skills
```

Or search for skills:

```bash
npx find skill
```

## Usage

After installation, activate a skill by name in your AI coding assistant.
