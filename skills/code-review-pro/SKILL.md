# 代码审查规范

## 工作流

1. 分析用户提交的代码变更。
2. 检查代码质量问题（如潜在bug、安全漏洞）。
3. 评估代码风格和最佳实践遵循情况。
4. 提供具体的改进建议。

## 审查范围

- **代码逻辑**：检查潜在bug和边界情况
- **安全性**：检测常见的安全漏洞（如SQL注入、XSS）
- **性能**：识别性能瓶颈和优化机会
- **可维护性**：评估代码结构和可读性
- **最佳实践**：确保遵循语言和框架的最佳实践

## 输出格式

审查报告将包含：
- 问题严重级别（Critical/Warning/Info）
- 具体文件位置和行号
- 问题描述和修复建议
- 代码示例
